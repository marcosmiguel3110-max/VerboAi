Guía rápida

1. Conseguí tu token

Entrá a la app, iniciá sesión y andá a Settings → Clave API. Ahí generás un token tipo verboai-XXXXXXXXXXXX.

2. Elegí el ID del modelo

Usá el identificador nuevo verboaistudio/<NombreDelModelo>. Es el mismo modelo, pero con naming consistente para integraciones.

3. Pegalo en tu app

Mandá Authorization: Bearer verboai-XXXX y un JSON con mensaje + modelo al endpoint /api/v1/chat.

  1. Si usás la web, los créditos se comparten con la API.
  2. /api/v1/info y /api/v1/creditos no consumen créditos.
  3. Si pasás un modelo inválido o vacío, el backend cae a NewserLite.

Endpoints disponibles

POST /api/v1/chat principal

Envía un mensaje al modelo elegido. Soporta texto, imágenes y herramientas según el modelo.

curl -X POST https://verboai.duckdns.org/api/v1/chat \
  -H "Authorization: Bearer verboai-XXXX" \
  -H "Content-Type: application/json" \
  -d '{
    "mensaje": "Hola, quien eres?",
    "modelo": "verboaistudio/NewserLite"
  }'

GET /api/v1/info gratis

Devuelve los datos del token, créditos, modelo por defecto y catálogo disponible. Ahora también trae id por modelo. 

curl -H "Authorization: Bearer verboai-XXXX" \
  https://verboai.duckdns.org/api/v1/info

GET /api/v1/chats gratis

Lista tus conversaciones guardadas de la app web. Útil para paneles, sincronización o clientes propios.

curl -H "Authorization: Bearer verboai-XXXX" \
  https://verboai.duckdns.org/api/v1/chats

GET /api/v1/creditos gratis

Devuelve solo créditos restantes. Es la opción más liviana si no necesitás toda la metadata del token.

curl -H "Authorization: Bearer verboai-XXXX" \
  https://verboai.duckdns.org/api/v1/creditos

Si una IA necesita analizar la parte pública del proyecto, el flujo recomendado es: /ai.txt → /llms.txt → /info → /api/config. La app web principal existe, pero la experiencia interactiva requiere sesión; por eso esta zona pública concentra el contexto necesario para análisis y descubrimiento.

SWE-Bench Pro, Lite y Verifiable

En Verbo Code ya existe el módulo SWE-Bench Pro con estos datasets: SWE-Bench Lite, SWE-Bench Verifiable y SWE-Bench Pro. Hoy los modelos conectados ahí son NewserPlus y NewserAdvanced1.5.

Dataset Qué mide Modelo recomendado Cuándo usarlo
SWE-Bench Lite Subset más liviano y rápido para pruebas iniciales. verboaistudio/NewserAdvanced1.5 Comparaciones rápidas o smoke tests de coding.
SWE-Bench Verifiable Casos verificables con evaluación más controlada. verboaistudio/NewserAdvanced1.5 Medir consistencia técnica antes de correr tandas pesadas.
SWE-Bench Pro Benchmark más exigente para bugs y features reales. verboaistudio/NewserPlus Evaluación seria de agentic coding y resolución de issues complejos.
En términos prácticos: si querés “la mesa completa” para ingeniería de software real, NewserPlus + SWE-Bench Pro es la combinación alta. Si querés validar rápido sin gastar tanto, NewserAdvanced1.5 + Lite/Verifiable te da un punto medio muy útil.

Imágenes con IA

Si tu prompt describe una escena visual, un logo, una portada o algo claramente gráfico, Verbo AI detecta la intención y genera imagen automáticamente con los modelos que lo soportan.

  • NewserAdvanced genera imagen con buen balance velocidad/calidad.
  • NewserAdvanced1.5 usa dos capas para sacar más detalle y por eso tiene el límite de 2 imágenes por hora.
  • La imagen vuelve en imagen.url; si la URL es relativa, prependé el dominio.

Ejemplos de integración

JavaScript 
const TOKEN = "verboai-XXXX";
const URL = "https://verboai.duckdns.org/api/v1/chat";

async function preguntar(mensaje, modelo = "verboaistudio/NewserLite") {
  const resp = await fetch(URL, {
    method: "POST",
    headers: {
      Authorization: `Bearer ${TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify({ mensaje, modelo }),
  });
  const data = await resp.json();
  if (!resp.ok || !data.ok) throw new Error(data.error || "Error");
  return data;
}
Python 
import json
import urllib.request

TOKEN = "verboai-XXXX"
URL = "https://verboai.duckdns.org/api/v1/chat"

def preguntar(mensaje, modelo="verboaistudio/NewserLite"):
    body = json.dumps({"mensaje": mensaje, "modelo": modelo}).encode()
    req = urllib.request.Request(URL, data=body, method="POST")
    req.add_header("Authorization", f"Bearer {TOKEN}")
    req.add_header("Content-Type", "application/json")
    with urllib.request.urlopen(req, timeout=120) as resp:
        data = json.loads(resp.read().decode())
    if not data.get("ok"):
        raise Exception(data.get("error"))
    return data

Errores comunes

Código Qué significa Qué revisar
400 Falta el mensaje o el body está mal formado. Mandá JSON válido y revisá comillas/campos.
401 Token ausente, inválido o revocado. Usá Authorization: Bearer verboai-XXXX.
402 No alcanzan los créditos para ese modelo. Probá con Lite o recargá acceso/créditos.
403 Intentaste usar un modelo restringido, como NewserPlus. Necesitás permisos de admin/cuenta habilitada.
429 Límite por ventana alcanzado. Esperá y reintentá, o bajá a un modelo más liviano.
502 / 500 El proveedor de IA o la capa gratis no respondió bien. Reintentá en unos minutos.

CLI de terminal

Si preferís usar Verbo AI desde terminal, el cliente Python sigue disponible y es útil para chatear, consultar créditos y listar modelos.

# Guardar el token
python verboai.py login verboai-XXXX

# Chat interactivo
python verboai.py run

# Ver info del token
python verboai.py info
