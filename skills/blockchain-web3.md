# Skill: Blockchain / Web3 (Smart Contracts, DApps)

Trigger: el usuario pide un smart contract, DApp, integración con blockchain,
wallet, NFT, DeFi, o aplicación descentralizada.

- Preferí Solidity para Ethereum (EVM) y Rust para Solana.
- Para smart contracts: usá OpenZeppelin (audited contracts), nunca reinventes la rueda.
- Para testing: usá Hardhat (Ethereum) o Anchor (Solana) con tests unitarios e integration.
- Para frontend: usá ethers.js o viem (Ethereum), @solana/web3.js (Solana).
- Para wallets: integrá MetaMask (Ethereum) o Phantom (Solana) con walletconnect.
- Para NFTs: usá ERC-721 (estándar) o ERC-1155 (multi-token) con metadata IPFS.
- Para DeFi: usá Uniswap SDK (DEX), Aave (lending), o Curve (stablecoins).
- Para bridges: usá LayerZero (cross-chain) o Chainlink CCIP.
- Para oracles: usá Chainlink (price feeds, data feeds).
- Para deployment: usá Remix (quick test) o Hardhat/Truffle (production).
- Para security: auditá con Slither, MythX, o OpenZeppelin Defender.
- Para gas optimization: usá assembly, calldata, y batch operations.
