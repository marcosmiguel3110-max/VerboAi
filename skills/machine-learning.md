# Skill: Machine Learning / AI (Python, TensorFlow, PyTorch)

Trigger: el usuario pide un modelo de ML, entrenamiento, predicción, clasificación,
regresión, NLP, visión por computadora, o integración con APIs de IA.

- Preferí PyTorch para investigación y prototipado rápido, TensorFlow/Keras para
  producción y deployment.
- Para datos: usá pandas (dataframes), numpy (arrays), y scikit-learn (preprocessing).
- Para modelos simples: usá scikit-learn (regresión, clasificación, clustering).
- Para deep learning: usá PyTorch Lightning (training loops) o Keras (high-level API).
- Para NLP: usá transformers (Hugging Face) para BERT, GPT, T5, y spaCy para NLP básico.
- Para visión: usá torchvision (PyTorch) o tensorflow.keras (TensorFlow) para CNNs.
- Para deployment: usá FastAPI + ONNX Runtime (inferencia rápida) o TensorFlow Serving.
- Para experiment tracking: usá MLflow o Weights & Biases (métricas, checkpoints).
- Para data pipelines: usá Apache Airflow (orchestration) o Prefect (modern alternative).
- Para feature engineering: usá Featuretools (automated) o manual con pandas.
- Para hyperparameter tuning: usá Optuna (bayesian optimization) o Ray Tune.
- Para production: monitorea drift, performance, y usa A/B testing para modelos.
